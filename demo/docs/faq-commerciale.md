# FAQ commerciale Atelier Lumen (document fictif de démo)

Q : Combien coûte un projet complet ?
R : Cela dépend du nombre de types de documents et des intégrations. Le prix ferme est
donné à l'issue de l'atelier de cadrage. Ordre de grandeur d'un pilote : 15 000 à 30 000 € HT.

Q : Où sont hébergées les données ?
R : Dans l'Union européenne, chez un hébergeur certifié ISO 27001. Aucune donnée client
n'est utilisée pour entraîner des modèles.

Q : Combien de temps avant les premiers résultats ?
R : Les premières mesures de qualité arrivent en 2 à 3 semaines de pilote.

Q : Que se passe-t-il si l'IA se trompe ?
R : Chaque champ extrait a un score de confiance. Sous le seuil, le document part en
validation humaine. On mesure le taux d'erreur chaque semaine.

Q : Est-ce compatible avec notre ERP ?
R : Oui pour les ERP courants via API ou export de fichiers ; le mode d'intégration est
validé pendant l'atelier.

Q : Quelle est la taille de l'équipe ?
R : 6 personnes : 4 ingénieurs IA et data, 1 cheffe de projet, 1 fondateur.
